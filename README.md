# user-authentication-php
# 🔐 User Management & Authentication System

A dynamic web backend application built with PHP and MySQL featuring role-based access control, secure authentication, and session management.

## 📌 Project Overview
Developed to handle web user authorization, user profile CRUD operations, and administrative department mappings. It features custom session persistence algorithms and data sanitization to ensure secure operations.

## 🚀 Features
- 🔹 **Authentication & Security:** Secure login/logout flows using PHP `$_SESSION` and `$_COOKIE` state handling.
- 🔹 **User Profile Management:** Full CRUD (Create, Read, Update, Delete) interface for user accounts.
- 🔹 **Database Integration:** Relational MySQL backend managed via optimized `mysqli` queries.
- 🔹 **Dynamic UI Rendering:** Dynamic HTML5 components rendered conditionally based on user authentication state.

## 🛠️ Tech Stack
- **Backend:** PHP 8.x
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3
